# Calorie Burnt Predictor System

An end-to-end Machine Learning project that predicts calories burned during exercise using physiological and workout-related features.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- FastAPI
- Streamlit
- PostgreSQL
- Docker
- MLflow
- DVC
- GitHub Actions
